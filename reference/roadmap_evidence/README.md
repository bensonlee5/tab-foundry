# Roadmap Evidence Notes

Use this directory for the canonical long-form evidence notes attached to
TF-RD-018 and every later research-oriented roadmap epic.

Use these alongside this index:

- [reference/papers.md](../papers.md): shared bibliography and adoption tiers
- [reference/evidence.md](../evidence.md): compact cross-epic evidence map
- [docs/development/roadmap.md](../../docs/development/roadmap.md): canonical
  roadmap ordering and exit criteria

Conventions:

- one file per research-oriented epic
- filename pattern: `tf_rd_<id>_<slug>.md`
- each file must include roadmap link, status and milestone, dependency
  position, external evidence, repo-local evidence, current interpretation or
  working defaults, open evidence gaps, and exit signals
- if dedicated external literature is not yet curated, say so explicitly and
  record the next sources to curate instead of inventing weak evidence
- use predecessor and successor epic links when handoff order matters
